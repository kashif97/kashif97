# 💫 About Me:
Hi, I'm Kashif, a backend-focused software engineer with an interest in building scalable and reliable systems. I completed my M.Tech in Computer Science from International Institute of Information Technology Hyderabad. I enjoy working on backend services, APIs, and data processing systems using technologies like Java, Spring Boot, and distributed data tools. I like solving real engineering problems and learning more about distributed systems, system design, and backend architecture.
